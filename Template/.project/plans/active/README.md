# Aktive Pläne

Hier liegen freigegebene Implementierungspläne.

Ein Plan ist führend für den Inhalt und Status seiner Steps.

Empfohlenes Format:

```markdown
# Plan — <Titel>

**Status:** In Progress
**Current step:** T-001

## Steps

### T-001 — <Titel>

- [ ]
- Do: <genau eine abgegrenzte Änderung>
- Verify: <reale Prüfmethode>
- Verified: NOT RUN
```

`Verified` darf nur reale Ergebnisse enthalten. `Current step` bzw. der erste offene Step beschreibt nur die Position im Plan; daraus entsteht keine Freigabe zur Umsetzung.
