# Work ChangeLog

Nur tatsächlich abgeschlossene und verifizierte Steps werden hier eingetragen.

Empfohlenes Format:

```markdown
## YYYY-MM-DD

### T-003 — <Titel>

Geändert:
- <Datei>

Grund:
<Kurz>

Umsetzung:
<Kurz>

Verifikation:
- Methode: <...>
- Status: PASSED | MANUAL_VERIFIED | ...
- Ergebnis: <...>
```

Der ChangeLog-Eintrag entsteht erst beim Step-Abschluss, nicht bei jedem Dateifragment.
