# Praxisbeispiele

Diese Beispiele gehören nicht zwingend zum Kern-Workflow. Sie zeigen, wie sich das Prinzip auf spezielle Aufgaben anwenden lässt.

- `chunked-processing/` – große Eingaben deterministisch vorbereiten und nur in kleinen Ausschnitten an das Modell geben.
- `knowledge-synthesis-workflow/` – Quellen kontrolliert aufnehmen, thematisch verdichten und erst danach finalisieren.

Beide Beispiele folgen demselben Grundsatz wie der Haupt-Workflow: klassische Skripte erledigen deterministische Arbeit; das LLM bekommt nur den Kontext, den es für die aktuelle Entscheidung wirklich benötigt.
