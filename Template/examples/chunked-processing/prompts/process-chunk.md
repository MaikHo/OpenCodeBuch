# Einen Chunk bearbeiten

Bearbeite ausschließlich den angegebenen Chunk.

Regeln:

1. Keine weiteren Chunks laden.
2. Keine externen Fakten ergänzen.
3. Relevante Informationen strukturiert verdichten.
4. Das Ergebnis unter `work/results/<chunk-name>.md` vorschlagen.
5. Nach diesem Chunk stoppen.
6. Nicht automatisch mit dem nächsten Chunk fortfahren.
