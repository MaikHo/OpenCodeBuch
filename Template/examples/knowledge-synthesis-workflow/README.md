# Knowledge Synthesis Workflow

Neutrale Vorlage für die kontrollierte Einarbeitung vieler Quellen in eine thematisch organisierte Dokumentation.

## Phasen

1. `source-intake` – Quelle validieren und Themen zuordnen
2. `topic-synthesis` – genau ein Thema mit relevanten Ausschnitten ergänzen
3. `source-finalization` – Vollständigkeit prüfen und Quelle abschließen

Die Vorlage enthält absichtlich keine fachliche Domäne.
