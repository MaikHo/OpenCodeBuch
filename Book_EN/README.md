# Book – English Edition

This book explains the controlled OpenCode workflow implemented by the accompanying `Template/`.

Start here: [CONTENTS.md](CONTENTS.md)

The chapters are deliberately compact. A concept is explained in one place where possible and only applied later instead of being explained repeatedly.

The practical files live in the separate [`../Template/`](../Template/README.md) directory. For day-to-day work with OpenCode, the German [`Benutzerhandbuch`](../Template/docs/BENUTZERHANDBUCH.md) is currently the detailed operational reference. The commands, paths and workflow described in this English book refer to exactly the same template.
